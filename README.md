# FitLog - Assignment 6

This is my submission for the Workout Library assignment. It's a simple fitness tracking app built with Next.js.

Live Website: (ekhane amar vercel link dibo)

# Features I implemented:
 Shows a list of workout cards
 Users can add exercises to "My Plan"
 Calculates total burned calories automatically
 we can remove items from the plan 
 Used LocalStorage so the plan doesn't disappear when we reload the page (this part took me a while to get right)

# Tools used
 Next.js & React
 Tailwind CSS

# How to run
Run `npm install` and then `npm run dev`. Open localhost:3000 to see the app.
